1. 什么叫 10 分价值

不是功能打分，而是真实交易质量打分。

Definition

1. 少犯错

能阻止冲动交易、重仓、追高杀跌、策略失效后继续交易。系统要敢拒绝你。

2. 控亏损

每单先算最大亏损，账户日损、连续亏损、策略预算和仓位暴露自动降级。

3. 会等待

不是预测价格，而是提前生成 15/30/60 分钟 A/B/C/D 场景和操作预案。

4. 可复盘

信号、拒绝、下单、撤单、止损、错过机会全部入账，能复原当时为什么做或不做。

5. 会进化

每周从结果里生成候选改进，但必须经过 backtest、paper、shadow 和人工批准。

6. 私有优势

H5 Excel、你的交易哲学、真实决策数据和多 agent 知识库组合成别人复制不了的系统。

2. 七个 10 分引擎

所有产出都要往这七个引擎靠。

7 engines
引擎10 分要求第一阶段验收
Research Evidence Engine来源、时间戳、反方观点、证据强弱、交易影响缺一不可。每份 packet 至少 3 类来源和 bull/bear/risk 三方意见。
H5 Structure Engine中轴、Keltner/ATR、均线成本、2B、VSA、价量时空都只是证据层。每张信号卡显示结构、失效、最大亏损和目标空间。
Scenario Engine只推演，不预测。A/B/C/D 都要有触发、等待、动作、失效。每个重点标的都能生成未来 15/30/60 分钟预案。
Risk Kernel确定性硬门。LLM 不能改风控，用户也不能绕过审计。所有 order intent 有 max_loss、risk_pct、daily_loss_remaining。
Execution Control EngineSignal、Paper、Semi-auto、Auto API 分级，默认不允许 live。P0 只出 Signal/Paper，P1 才有半自动草稿。
Decision Ledger不交易、拒绝、等待、止损和错过机会都算结果。每次 action 都有 input_hash、reason、operator、outcome。
Growth Curator进化靠证据，不靠模型自信。候选升级必须走验证链。每周输出：应保留、应降级、应测试、应禁止的策略/参数。
10 分价值公式： Value_10 = BadTradeAvoided + MaxLossKnown + HighRRWaited + EvidenceGrounded + RiskRejected + ReviewCompounded 不能量化这六项，就不是 10 分产品。 不能持续跑这六项，就只是漂亮交易界面。

3. 护城河怎么形成

不是靠一个策略，而是靠数据闭环和纪律闭环。

Moat

别人能复制的

  • 技术指标。
  • TradingView 脚本。
  • 多 agent 架构。
  • Binance API 接入。
  • 普通回测报告。

别人难复制的

  • 你的 H5 交易思想和金木水火土框架。
  • 每次不交易、止损、错过、等待的真实决策数据。
  • 策略在不同市场状态下的失败画像。
  • Risk Kernel 拒绝记录和后续结果对比。
  • 长期复盘后形成的私有参数和情境库。
护城河不是“预测更准”，而是“系统更懂你如何输钱，并持续减少这种输钱方式”。这才是真正值得做的 AI 交易系统。

5. 开发范围重新压缩

要做到 10 分，第一版反而要更窄。

Build narrow

P0 必做

  • Research Evidence Packet。
  • H5 StrategySpec。
  • Scenario A/B/C/D。
  • Risk Kernel v0。
  • Signal/Paper。
  • Decision Ledger。
  • Weekly Review。

P0 暂不做

  • 大额实盘。
  • 全市场自动交易。
  • 策略市场。
  • 复杂社交功能。
  • 多账户托管。
  • LLM 直接下单。
  • 自动修改 live 策略。

第一版胜负手

  • 能否清楚拒绝交易。
  • 能否提前算最大亏损。
  • 能否沉淀每次判断。
  • 能否每周输出可执行复盘。
  • 能否让你每天真的愿意用。

6. 10 分产品红线

踩中这些，价值会从 10 分掉回玩具。

No-Go
红线为什么危险替代做法
追求信号数量会鼓励乱交易。追求高质量等待和风控拒绝。
第一版 live auto错误会更快、更大。Signal/Paper -> Shadow -> Semi-auto。
指标拜物策略会拟合过去。用指标做证据层，用风控做硬门。
忽略不交易系统会变成开仓机器。把等待、拒绝、冻结做成一等结果。
复盘只写感想无法形成复利。结构化记录 outcome、reason、avoid_next_time。
AI 自由改策略不可审计且危险。只允许生成候选版本，走验证和人工批准。
