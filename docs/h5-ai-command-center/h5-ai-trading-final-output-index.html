3. 最终产品定义

一句话和模块化定义。

Product definition

一句话

H5 AI Trading Command Center 是一个以 H5 交易框架为核心、以 QuantDinger 产品骨架为参考、由多 agent research 和确定性风控驱动的 AI 交易飞控系统。

第一版定位

Stark 自用的交易工作台：先做研究、评分、场景、风控、通知、paper 和复盘，不急着做大额 live auto。

长期方向

从单策略包扩展到多策略注册、跨市场 research、半自动执行、受控自动交易和自我成长的交易操作系统，但始终以减少坏交易和控制亏损为第一价值。

正确工作流：标的扫描 -> research evidence -> H5 技术判断 -> 场景 A/B/C/D -> Risk Kernel -> Signal/Paper/Semi-auto -> 审计复盘 -> 候选升级。

4. 必须保留的原则边界

这是后续开发不能压缩错的重点。

Non-negotiables

H5 不是单指标策略

  • 中轴随品种波动和交易时长变化。
  • Keltner/ATR 是波动和风险距离证据，不是直接买卖按钮。
  • Wyckoff/VSA/MA/2B 都是 evidence layer。
  • 评分达标只进入风控，不等于允许执行。

AI 不是自由交易员

  • AI 可以 research、辩论、解释、提出候选。
  • LLM 不能直接持有交易 API key。
  • Live action 必须过 Strategy 状态机、Risk Kernel、前端授权。
  • 自我成长只能生成候选版本，不能自动改 live 策略。
核心纪律：赚钱是目的，但我们无法知道每单赚多少；系统必须先知道最多亏多少。不交易、等待、认输、止损、降级、冻结，都是系统能力。
